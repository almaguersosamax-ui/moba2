moba2-lan — servidor propio + parches para MOBA2
=========================================================

QUE HAY EN ESTE ZIP
  server.py            servidor (API /v1/* + panel de estadisticas), sin dependencias
  moba2/              codigo modular: config, db+migraciones, dominio (ELO), servicios, web
  tests/               13 pruebas automaticas:  python3 -m unittest discover -s tests -v
  patch_moba2.py      sistema de parcheo de la APK (IP configurable, re-aplicable)
  seed_demo.py         datos de ejemplo para ver el panel con partidas
  vendor/              apktool.jar y uber-apk-signer.jar (los usa el parcheador)
  docs/                informe tecnico del decompilado + plan del servidor
  README.md            guia completa (leer primero)

ARRANQUE RAPIDO
  1) Servidor:      python3 server.py --host-ip 192.168.1.105
     Panel:         http://192.168.1.105:8080/
     (opcional)     python3 seed_demo.py --url http://127.0.0.1:8080
  2) Parche de la APK (sobre la APK ORIGINAL, sin parchear):
     python3 patch_moba2.py --apk moba-fan-make-v1.1.apk --ip 192.168.1.105
     -> dist/moba2-patched-192_168_1_105-p8080.apk
  3) Instalar:
     adb uninstall <paquete>   # ver dist/INSTALAR.txt
     adb install -r dist/moba2-patched-192_168_1_105-p8080.apk

SI CAMBIA LA IP DEL SERVIDOR
  Vuelve a ejecutar el paso 2 con --ip NUEVA_IP (siempre sobre la APK original) e instala el nuevo APK.

LO QUE NECESITAS TENER
  - Python 3.9+            (sin pip install: todo es libreria estandar)
  - Java 8+ (JRE)          para apktool y el firmador
  - Las 2 herramientas ya estan en vendor/ (apktool.jar, uber-apk-signer.jar)
  - La APK original moba-fan-make-v1.1.apk
  - adb (Opcional)         para instalar y ver logcat

LIMITE IMPORTANTE
  La URL parcheada mide exactamente 30 bytes (igual que la original) para no romper el
  metadata IL2CPP. Si tu IP:puerto no cabe, usa --port 0 (servidor en :80) o un nombre corto.
  El relleno (p.ej. /pppp) lo ignora el servidor automaticamente.
